# Recorder releases

Installers for **Recorder**, a crash-safe lecture and meeting recorder for Windows on ARM.

Download the newest `Recorder_<version>_arm64-setup.exe` from [Releases](https://github.com/Epicfacewizzard/Recorder-releases/releases/latest) and run it. Installed copies (0.9.2 and later) check here for updates by themselves and offer to install them.

The source code is kept in a separate private repository. This repository only holds the installers, their update signatures and `latest.json`.
